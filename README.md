# Open Redirection Vulnerability Analysis and Exploitation using BurpSuite

## 📌 Project Overview
This project demonstrates the identification and exploitation of an Open Redirection
vulnerability using Security Headers analysis and BurpSuite Professional.

Open Redirection vulnerabilities occur when a web application redirects users to
external URLs without proper validation. Attackers can exploit this flaw to perform
phishing attacks, credential theft, and malicious redirections.

This project was performed on OWASP Juice Shop, a legal and intentionally vulnerable
web application used for educational purposes.

---

## 🎯 Objectives
- Identify weak or missing security headers
- Detect Open Redirection vulnerability
- Exploit the vulnerability using BurpSuite
- Demonstrate phishing attack scenario
- Assess security risks
- Propose mitigation strategies

---

## 🛠 Tools Used
- Security Headers (by Snyk)
- BurpSuite Professional
- Kali Linux
- OWASP Juice Shop

---

## 📂 Project Structure
- Security Headers Scan
- BurpSuite Setup & Configuration
- Open Redirection Testing
- Exploitation Demo (Phishing)
- Risk Assessment
- Mitigation Strategies
- Final Report
